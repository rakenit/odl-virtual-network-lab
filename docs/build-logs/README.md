# Historical Build Logs

This directory contains the original host and controller build notes for the virtual network lab.

These files are retained as implementation history and troubleshooting references. For audience-facing review, start with the top-level `README.md`, then use these logs only when deeper build details are needed.

Sanitization note: the logs preserve historical lab-local hostnames, RFC 1918 addresses, local paths, and vendor image filenames as examples. They do not include proprietary VM images, private keys, certificates, environment files, or real controller credentials. Replace the example values before using the lab in another environment.
